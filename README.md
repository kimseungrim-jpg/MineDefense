# MineDefense
몬스터로부터 광부를 지키기 위해 타워를 배치하고 강화하는 Unity 2D 타워 디펜스 게임입니다.

광부가 생산하는 광석과 전투로 흭득하는 골드를 활용해 타워를 강화하고 설치해 이어지는 웨이브에 대응합니다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | MineDefense |
| 장르 | 2D 타워 디펜스 |
| 개발 인원 | 1인 개발 |
| 개발 목표 | Unity 타워 게임의 시작부터 종료까지 전체 흐름의 완성 |
| 실행 플랫폼 | Windows |
